Prywatność i zgłaszanie błędów

Testy na Broń – Ochrona — niezależny projekt edukacyjny. Wersja testowa, aktualizacja: 23.10.2026.

Jakie dane zapisuje aplikacja?

Podczas samej nauki aplikacja zapisuje w pamięci lokalnej urządzenia (localStorage) pytania poznane, błędy, wyniki testów i historię. Te informacje nie są wysyłane przez aplikację do autora ani do Policji. Aplikacja posiada opcjonalne konta Firebase Authentication; w obecnej wersji nie wyświetla reklam ani nie ma włączonego analitycznego pomiaru zachowań.

Wyniki mogą zniknąć po usunięciu danych witryny lub przy zmianie urządzenia. W zakładce „Wyniki / kopia” można wyeksportować lub importować historię oraz wyczyścić postępy.

Konto Firebase (funkcja testowa)

Rejestracja i logowanie odbywają się przez Firebase Authentication firmy Google, co obejmuje adres e-mail, identyfikator konta i dane techniczne uwierzytelniania. Firestore przechowuje identyfikator konta, datę rozpoczęcia trzydniowej próby i uprawnienia dostępu. Hasło obsługuje Firebase Authentication — aplikacja nie przesyła go do właściciela repozytorium. Funkcja nie synchronizuje historii wyników. Po uruchomieniu płatności zaufana usługa backendowa będzie przechowywać techniczny zapis zweryfikowanego zakupu Google Play, jego identyfikator w postaci skrótu i termin wygaśnięcia. Przed wydaniem produkcyjnym należy doprecyzować podstawy prawne, okresy przechowywania i pełne dane administratora. Konto jest dobrowolne na etapie testów, ponieważ nauka pozostaje dostępna bez blokady. Informacje o przetwarzaniu danych przez usługodawcę: Firebase Privacy. Przed uruchomieniem sprzedaży i obowiązkowych kont administrator danych musi uzupełnić rzeczywiste dane kontaktowe, podstawy prawne i okresy retencji.

Zgłaszanie błędów

Po użyciu przycisku „Zgłoś błąd” można przejść do zewnętrznego serwisu GitHub Issues. GitHub wymaga zalogowania, a opis zgłoszenia zostaje opublikowany publicznie w repozytorium. Nie należy tam zamieszczać danych osobowych. Zgłoszenia przegląda opiekun repozytorium djfokus176-stack. Właściwe zasady konta i przetwarzania danych przez GitHub określa polityka prywatności GitHub.

Hosting strony

Strona jest hostowana na GitHub Pages. Dostawca hostingu może przetwarzać techniczne dane połączenia (np. adres IP) zgodnie z własnymi zasadami. Program nie wysyła do hostingu wyników testów.

Kontakt i korekty

Kontakt w sprawie danych i aplikacji: djfokus176@gmail.com; wątpliwości dotyczące pytań można też zgłosić przez GitHub Issues. Można tą drogą zgłosić również prośbę o usunięcie konta i danych. W obecnej wersji nie wdrożono jeszcze automatycznego usuwania konta w aplikacji. Przed komercyjnym wydaniem należy uzupełnić dane administratora, informację o retencji i przeanalizować obowiązki RODO i wymogi Google Play dotyczące usuwania konta.
