Prywatność i zgłaszanie błędów

Testy na Broń – Ochrona — niezależny projekt edukacyjny. Wersja testowa, aktualizacja: 20.10.2026.

Jakie dane zapisuje aplikacja?

Podczas samej nauki aplikacja zapisuje w pamięci lokalnej urządzenia (localStorage) pytania poznane, błędy, wyniki testów i historię. Te informacje nie są wysyłane przez aplikację do autora ani do Policji. Nie ma kont użytkowników, reklam, analityki ani narzędzi śledzących dodanych do aplikacji.

Wyniki mogą zniknąć po usunięciu danych witryny lub przy zmianie urządzenia. W zakładce „Wyniki / kopia” można wyeksportować lub importować historię oraz wyczyścić postępy.

Konto Firebase (funkcja testowa)

Po włączeniu metody logowania Email/Password w panelu Firebase, rejestracja i logowanie odbywają się przez Firebase Authentication firmy Google; projekt Firestore może przechowywać identyfikator konta, datę rozpoczęcia trzydniowej próby i uprawnienia dostępu. Hasło obsługuje Firebase Authentication — aplikacja nie przesyła go do właściciela repozytorium. Funkcja nie synchronizuje historii wyników. Konto jest dobrowolne na etapie testów, ponieważ nauka pozostaje dostępna bez blokady. Informacje o przetwarzaniu danych przez usługodawcę: Firebase Privacy. Przed uruchomieniem sprzedaży i obowiązkowych kont administrator danych musi uzupełnić rzeczywiste dane kontaktowe, podstawy prawne i okresy retencji.

Zgłaszanie błędów

Po użyciu przycisku „Zgłoś błąd” można przejść do zewnętrznego serwisu GitHub Issues. GitHub wymaga zalogowania, a opis zgłoszenia zostaje opublikowany publicznie w repozytorium. Nie należy tam zamieszczać danych osobowych. Zgłoszenia przegląda opiekun repozytorium djfokus176-stack. Właściwe zasady konta i przetwarzania danych przez GitHub określa polityka prywatności GitHub.

Hosting strony

Strona jest hostowana na GitHub Pages. Dostawca hostingu może przetwarzać techniczne dane połączenia (np. adres IP) zgodnie z własnymi zasadami. Program nie wysyła do hostingu wyników testów.

Kontakt i korekty

Na etapie testowym kontakt ze wspierającym projektem możliwy jest przez zakładkę Zgłoszenia na GitHubie. Przed komercyjnym wydaniem należy uzupełnić informacje o administratorze danych (pełne dane podmiotu i bezpośredni kontakt) oraz przeanalizować obowiązki RODO zależnie od finalnej funkcjonalności i sposobu zbierania zgłoszeń.

Powiązania

Aplikacja nie jest produktem Policji ani innego organu administracji rządowej i nie umożliwia składania urzędowych wniosków.
